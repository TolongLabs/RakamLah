## [0.1.0] - 2026-09-14

### Added

- Portable ESM configuration and framework-neutral scenario adapter.
- Headless `doctor`, `validate`, `capture`, `narrate`, `run`, and `verify` commands with JSON output.
- Playwright browser capture with ordered visual beats, minimum holds, linear scrolling, warm-up, audit, and cleanup.
- Beat-aware local Kokoro and Chatterbox narration, two-row subtitles, optional ducked BGM, and H.264/AAC assembly.
- Independent deliverable verification for duration, streams, dimensions, and required beats.
- Self-contained local browser example, product-neutral agent tooling, redistributable audio library, and integrity checks.
