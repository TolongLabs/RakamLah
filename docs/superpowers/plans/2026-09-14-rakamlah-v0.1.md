# RakamLah v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish RakamLah v0.1.0 as a portable, agent-friendly browser recording suite with a verified neutral example,
bundled media, public roadmap, and polished TolongLabs repository surface.

**Architecture:** A dependency-light Node ESM CLI loads a portable project configuration and scenario adapter, delegates
browser capture to Playwright, delegates speech/subtitle scheduling to focused Python utilities, and delegates final
media assembly to ffmpeg. All human and agent entrypoints converge on the same headless commands and verified artifacts.

**Tech Stack:** Node.js 20.11+, Playwright, Python 3.11, ffmpeg/ffprobe, Chatterbox/Kokoro, pnpm, Git LFS, GitHub CLI.

**Spec:** `docs/superpowers/specs/2026-09-14-rakamlah-v0.1-design.md`

## Global Constraints

- The repository is an independent TolongLabs product and contains no references to unrelated projects or stale URLs.
- `AGENTS.md` remains below 200 lines and delegates detail to `docs/`.
- Interactive CLI/TUI customization is roadmap-only in v0.1.0.
- Headless JSON commands never prompt and emit one final JSON object to stdout.
- New runtime behavior follows test-first red-green-refactor.
- MP3 assets are copied byte-for-byte, tracked through Git LFS, checksummed, and covered by explicit media terms.
- No credentials, `.env`, absolute developer path, generated media, model cache, prompt, or worker log is committed.
